### 6.1 目录结构固定

### 6.2 客户端核心渲染函数（不可删减逻辑）
renderBoard、renderPieces、renderSide、renderLedger、renderActionBar、renderPending、openCityDetail、openBank、openAssetOverview、sellChoice、openReceipt、renderStock/adjStock/submitStock、renderTransfer/adjTransfer/submitTransfer、handleTradeConfirm、renderGameOver、buildRules；以及棋子移动动画、骰子动画、动画编排（processState/afterAnim/finishRender）。

### 6.3 Socket 双向数据契约
- 客户端发送（emit）：createRoom、joinRoom、reconnect、startGame、action、disbandRoom。
- action 类型全套：roll_dice、respond_frozen(pay/pass)、respond_jail(pay/roll/pass)、buy(buy/pass)、buy_airport(buy/pass)、flight(target|null)、stock_trade(orders[buy/sell])、stock_done、stock_transfer(targetId,items,cash 或 accept)、auction_respond(bid/pass)、direct_sale_respond(buy/pass)、rescue_mortgage、rescue_demolish、rescue_done、mortgage、redeem、sell_city(cityId,mode,direct/auction,context?)、build_house、demolish_house、surrender。
- 服务端推送（on）：roomState、gameState、timerStarted、error、reconnectToken。
- gameState 包含玩家资产、棋盘地块、城市、机场、股票、回合阶段、事件日志、结算排名全套数据；events 为全局事件字段（完整事件，每项含 {text,type,id}）。

### 6.4 核心回合流程固定
等待掷骰 → 掷骰动画 → 棋子移动动画 → 落点判定（购买/租金/机会卡/监狱/极地/机场）→ 结束回合轮换玩家；经过起点发放资金 + 股息 + 自动弹出股票交易窗口。

### 6.5 特殊规则逻辑固定
- 监狱：21 号监狱 3 回合——支付 15000 / 掷出 1 或 10 出狱 / 放弃（跳过判定、关押回合 +1）/ 第 3 回合开始自动释放并正常行动（出狱费仅用于提前出狱、非强制）；11/32 号监狱 1 回合——该回合跳过、下回合自动释放（无需缴费）
- 极地冰冻：支付 5000 解除冻结，否则跳过整回合
- 破产 / 认输：认输资产直接归银行（不拍卖）；破产走逐城拍卖；剩余玩家按出局顺序排名结算
- 断线重连：localStorage 存储房间、昵称、一次性重连令牌，掉线自动暂停对局等待重连
