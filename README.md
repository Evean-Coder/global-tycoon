# 环球大亨（大富翁联机游戏）

网页版实时联机大富翁。2–4 名玩家通过房间码开局，围绕 42 格世界地图买卖地产、建设城市、投资股票、经营机场，破产淘汰制决出最终赢家。

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm start
```

浏览器打开 `http://localhost:3000`。

## 手机/局域网访问

1. 服务端监听 `0.0.0.0`（默认已开启）。
2. 手机与电脑连同一 WiFi，在手机浏览器打开 `http://电脑局域网IP:3000`（电脑上 `ipconfig` 查看 IPv4 地址）。
3. 若无法访问，请在 Windows 防火墙放行 3000 端口。

## 测试

```bash
npm test
```

单元测试覆盖规则引擎（移动/收租/建房/抵押/拍卖/股票/破产等），集成测试验证房间创建、加入、开始与首个回合的端到端流程。

## 对局数据记录

每场对局结束后，服务端会生成一份完整对局记录（JSON）：对局信息（房间码、起止时间、结束方式、回合数）、玩家结算（排名、现金、总资产、城市明细含房屋/抵押、机场、持股）、完整事件流水、关键统计（破产/认输/机会卡/入狱/拍卖/租金/抵押次数、各城市成交与租金支付次数）。

- 对局结束或中途解散时，结算界面房主可见「下载对局数据」按钮，点击下载 JSON 文件。
- 把收集到的文件放入项目根目录 `records/` 文件夹，运行 `node scripts/analyze-games.js` 查看汇总统计；`node scripts/analyze-games.js --detail <文件>` 查看单局完整事件。

## 房间清理

- 房间最后一名在线玩家断开后进入闲置计时：大厅（未开局）房间闲置 10 分钟、对局中或已结束房间闲置 30 分钟后自动清理，释放内存与房间码；任一玩家加入或重连即取消计时。
- 对局进行中因全员离线被清理时，服务端自动补生成一份「闲置超时」对局记录并写入 `records/` 目录；正常结束的对局记录由房主在结算界面点击下载。
## 项目结构

```
server.js          网络、房间、重连、倒计时、广播
src/board.js       棋盘、城市、机场、机会卡数据
src/gameLogic.js   规则引擎（纯函数）
src/state.js       对局状态容器
src/random.js      随机源（可注入）
src/record.js      对局记录生成与统计
scripts/analyze-games.js  对局记录批量分析工具
public/            前端（原生 HTML/CSS/JS）
test/              单元与集成测试
```

## 部署

本机运行后，可将服务部署到免费托管平台（如 Render 免费层），或使用内网穿透（cpolar/ngrok）临时生成公网链接供朋友访问。

## 规则要点

- 回合：掷单个骰子（1–10，洗牌袋机制：每 10 次掷骰 1–10 各出现一次、顺序随机），点数即移动格数（无连掷/三双入狱）；跨过起点 +5000 并触发股息与股票交易窗口；每圈最多获得 4 座城市（机场不限；购买、拍卖与直接出售所得均计入）。
- 地产：租金 = 地价 ×（30% + 房屋等级 × 30%）；地价 ≥15000 的城市满级租金 +10%；经过自有城可建/拆 1 级。
- 城市交易：直接出售（卖家得 80%）或拍卖（起拍 75%、每次加价至少 1000）。
- 抵押：总价值 × 50%，同时最多 2 座，每轮 5% 利息。
- 机场：15000 购买，机场费 3000 × 拥有数，机票 = 距离 × 500。
- 股票：每城 20 股（1 股 = 5%）、初始股价 = 地价 ÷ 10 × 2，经过起点可买卖；收租时持股阶梯减免租金（<20% 不减、≥20% 且 <40% 减 10%、≥40% 且 <60% 减 30%、≥60% 减 50%）；城市所有者过起点派发股息。
- 极地/监狱：冰冻付 5000 解除；21 号监狱付 15000 或掷出 1/10 提前出狱（一直放弃则关满 3 回合、第 4 回合自动释放，80 轮后缴纳 30% 出狱费），11/32 号监狱关押 1 回合（下一回合跳过、再下一回合自动释放）。玩家破产时发放 15000 救济金（分给资产未达最高的存活玩家，资产最高者除外）。

完整规则见 `spec.md`。


## 免费托管部署（Render）

1. 将本项目推送到 GitHub 仓库。
2. 登录 render.com → New → Web Service → 连接该仓库。
3. 构建命令填 `npm install`，启动命令填 `npm start`，实例选 Free。
4. 部署完成后打开分配的 `https://xxx.onrender.com` 地址即可（手机电脑通用，支持 WebSocket）。
5. 注意：免费实例闲置约 15 分钟会休眠，首次访问需等待几十秒；重启后房间数据清空，重新建房即可。
